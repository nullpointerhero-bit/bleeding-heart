# Bleeding Heart

A NeoForge mod for Minecraft 1.21.1 that adds a Blood fluid that doesn't evaporate in the Nether.

## Features
- The **Blood fluid**, which behaves like water in all aspects other than evaporating in the Nether.
- You can obtain a **Bucket of Blood** by killing any mob while holding an empty bucket in your offhand.
